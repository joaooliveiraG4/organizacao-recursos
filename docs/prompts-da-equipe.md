# Prompts de entrada para a equipe

Cada integrante deve clonar o repositório, abrir sua raiz no Codex e usar o próprio prompt. O `AGENTS.md` faz o agente carregar as instruções locais automaticamente; não é necessário instalar a skill separadamente. Esses textos dão autorização para branch, implementação, push e PR; não autorizam merge.

## João

```text
Sou o João. Siga o AGENTS.md e as instruções locais do projeto. Mostre o estado atual das minhas responsabilidades e as tarefas disponíveis. Quero escolher uma tarefa antes de qualquer alteração. Depois que eu escolher, faça a orientação educativa prevista, valide meu entendimento e, quando estivermos alinhados, você está autorizado a criar uma branch, implementar comigo, executar os testes, atualizar a documentação e a RTM, fazer push e abrir uma pull request. Não faça merge.
```

## Miranda

```text
Sou a Miranda. Siga o AGENTS.md e as instruções locais do projeto. Explique de forma simples o que o professor espera, o que a equipe vai entregar e quais partes ficaram sob minha responsabilidade. Liste minhas tarefas para eu escolher uma. Depois da escolha, ensine o fluxo e os critérios, faça perguntas curtas para confirmar meu entendimento e então você está autorizado a criar minha branch, implementar comigo, testar, atualizar a RTM, fazer push e abrir a pull request. Não faça merge. No fim, gere a mensagem com o link para eu enviar ao João no WhatsApp.
```

## Kauã

```text
Sou o Kauã. Siga o AGENTS.md e as instruções locais do projeto. Primeiro valide que meu pedido pertence ao projeto, explique em linguagem simples o trabalho completo e liste somente as tarefas que foram atribuídas a mim. Quero escolher por qual começar. Explique o valor da tarefa e use exemplos antes de codificar; faça perguntas para confirmar que entendi. Após minha escolha e alinhamento, você está autorizado a criar uma branch própria, implementar comigo, executar os testes, atualizar a RTM, fazer push e abrir a pull request. Não faça merge. No final, me dê o link e a mensagem pronta para enviar ao João no WhatsApp.
```
